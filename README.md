## 🎨 Visual Identity & Mandatory Constraints
- **Brand Colors**: Mandatory **Electric Cyber Yellow** (`#FACC15`) & **Deep Obsidian Purple** (`#7C3AED` / `#090514`).
- **Typography Stack**:
  - Headings: `Syne` & `Space Grotesk` (bold, confident brutalist hierarchy).
  - Body & UI: `Plus Jakarta Sans` & `Inter`.

- **Aesthetic**: Modern Glassmorphic Brutalism with ambient purple glows, high-contrast yellow CTAs, and custom technical SVG illustrations.

## ⚡ Core Sections & Feature Highlights

1. **⚡ Fast Tech Preloader (1.2s)**
   - Matrix boot sequence: `"DKODER OS v2.4 // LOADING PLACEMENT MATRIX..."` before revealing the landing page.
2. **💎 Sticky Glassmorphism Header**
   - Dkoder Pro logo, pulsating live beacon (`🟢 24H HACKATHON LIVE`), quick jump anchors, and Yellow CTA.
3. **🔥 High-Impact Hero Section**
   - Heavyweight headline: *"Consistency Today. Placements Tomorrow."*
   - **Interactive AI Placement Dream Terminal**: Switch between goals (*₹10 LPA Dream*, *Crack Zoho*, *TCS Digital*) with live typewriter response.
   - **Live 24H Hackathon Status Card**: Real-time ticking countdown to **2:00 PM**, ₹3,000 stipend badge, and instant submit button.
4. **📊 Live Metrics & Hiring Partner Marquee**
   - Counter numbers: `12,500+ Questions`, `500+ Companies Tagged`, `94.2% Batch Consistency`.
   - Infinite logo marquee of hiring partners (Zoho, TCS, Infosys, Amazon, Cognizant, Google, Wipro).
5. **💻 Interactive Practice Lab & Live Code Runner**
   - Company tags & salary bracket filters (₹3.6 – ₹18+ LPA).
   - **Interactive Mini Code Sandbox**: Language switcher (JavaScript, Python, Java, C++) with an interactive **"Run Test Cases"** button that compiles and passes 3/3 test cases with performance metrics.
6. **🏫 "Now Imagine Seeing the Whole Batch" (College & HOD Batch Radar)**
   - SyncAura-inspired technical SVG cards: Batch Consistency Curve, Topic Blocker Diagnostics, and Proctored Security Shield.
   - Institutional MOU inquiry trigger.
7. **🏆 24H Solo Hackathon Arena & Live Project Submission Modal**
   - 4-Pillar Evaluation Rubric (Design 25%, Creativity 25%, Brand Fit 25%, Impact 25%).
   - Functional Submission Modal with real-time GitHub & Live URL regex validation + **Canvas Confetti celebration** burst!
8. **🌟 Placement Wall of Fame & High-Conversion Footer**
   - Real student placement journeys (Zoho ₹8.5 LPA, TCS Digital ₹7.6 LPA, Amazon ₹16.5 LPA).

## 🛠️ Tech Stack
- **Framework**: React 18+ (Vite)
- **Styling**: Tailwind CSS v4 + Custom Glassmorphism CSS
- **Animations**: GSAP 3 + `@gsap/react` (`useGSAP`)
- **Icons**: Lucide React
- **Celebration Effects**: Canvas Confetti
